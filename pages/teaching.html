Teaching

ICT learning that moves from theory to competence.

Lessons, practical work, troubleshooting and assessment designed to help learners actually use technology.

Method

The learning cycle

01

Explain

Build the concept with clear language, examples and visual demonstrations.

02

Demonstrate

Show the exact procedure before learners attempt the task independently.

03

Practise

Use practical activities, scenarios and progressive challenges.

04

Assess

Use evidence from learner performance to identify strengths and weaknesses.

Curriculum

From foundational ICT to advanced application.

Resources can be organised by class, topic, competency, paper and difficulty so learners can revise strategically rather than randomly.

Useful assessment dimensions

  • Knowledge and recall
  • Understanding
  • Application
  • Analysis
  • Troubleshooting
  • Evaluation
  • Creation
